## 3. 실행 전 발견한 문제 3건

### 3.1 🔴 MPS(Apple Silicon) 백엔드의 조용한 오답 — 심각

이 환경(torch 2.8.0, macOS arm64)에서 `Conv2d(8, 16, (64,1), groups=8)` (EEGNet의 depthwise
spatial conv)가 **batch ≥ 32에서 CPU와 다른 값을 반환**합니다. 예외도 경고도 없습니다.

| batch | logit 최대 오차 | 예측 일치율 |
|---|---|---|
| 16 | 2.7e-07 | 1.000 |
| 32 | **2.15** | **0.375** |
| 64 | **3.91** | **0.438** |

영향: v4 fusion 체크포인트를 MPS로 평가하면 정확도가 **74.0% → 52.6%** 로 보입니다.
그대로 믿었다면 "오염 배제로 성능 붕괴"라는 완전히 틀린 결론을 냈을 것입니다.

대응: `ablation_study_v5.py` 에 자가진단(`_mps_grouped_conv_is_broken`)을 넣어 EEGNet 계열
조건은 MPS를 자동으로 거부하도록 했습니다. EMG BiLSTM 경로는 CPU와 일치(3e-7)함을
forward/backward 모두 확인했으므로 `emg_only` 만 MPS 사용을 허용합니다.

### 3.2 🟡 지시서 §2.4의 하이퍼파라미터가 실제 코드와 불일치

| 항목 | 지시서 §2.4 | 실제 v4 코드 |
|---|---|---|
| scheduler | cosine annealing T_max=100 | **저장소 어디에도 없음** |
| max epoch | 100 | 200 |
| early stopping patience | 15 | 20 |
| batch size | 64 | 32 (학습) / 64 (평가) |

`ablation_study.py` 와 `S3_Model_Training_MemberA.ipynb` 의 `CONFIG` 를 모두 확인한 결과입니다.
**실제 v4 값을 사용**했습니다 — "유일한 차이가 데이터여야 한다"는 §6 원칙을 지키려면 그래야 합니다.
원고에 cosine annealing이 기재돼 있다면 그것도 사실과 다릅니다. 확인이 필요합니다.

### 3.3 🟡 early stopping이 테스트 fold로 이루어짐 (v4부터 존재)

`ablation_study.py:330` 및 S3 노트북 모두, 매 epoch **테스트 fold의 macro-F1**으로 조기종료를
판단하고 그 최고 지점의 가중치를 최종 모델로 채택합니다 (`# val: test set으로 조기종료`).
검증 세트가 따로 없습니다.

이는 보고된 절대 정확도를 낙관적으로 편향시킵니다. 지시서 §6에 따라 **v5에서도 그대로 유지**했습니다
(v4와 v5가 같은 프로토콜이어야 차이를 데이터 효과로 읽을 수 있으므로). 다만 JNE 리뷰어가 지적할
가능성이 높은 지점이며, v4/v5 **비교**는 유효하되 **절대값**은 그대로 주장하기 어렵습니다.

## 4. 부(secondary) 분석 결과 — 완료

`src/secondary_eval_v5.py`. v4 fusion 체크포인트 51개를 그대로 불러 (a) 전체 trial, (b) clean trial만
평가. 학습된 표현이 동일하므로 차이는 **평가 데이터의 오염분**만 반영합니다.

### 4.1 파이프라인 무결성 검증 (선행 조건)

전체 trial 재평가값이 v4 발표값과 **51명 전원 완전 일치** (최대 |Δ| = 0.000000).
→ 본 보고서의 `BCIDataset` / `evaluate` / `_metrics` 는 v4와 bit 단위로 동일합니다.

### 4.2 결과

| 지표 | 전체 trial | clean only | Δ |
|---|---|---|---|
| Fusion accuracy | 0.7399 | 0.7314 | **−0.85%p** |
| Fusion κ | 0.4797 | 0.4566 | −0.023 |

Wilcoxon (51명 paired): W=176, **p=0.023** — 작지만 유의한 하락.

### 4.3 게이트는 오염 trial에 sEMG 가중치를 더 준다 ← 새 증거

오염 trial을 보유한 35명 한정:

| | clean trial | 배제(오염) trial |
|---|---|---|
| mean w_sEMG | 0.3737 | **0.4528** |
| accuracy | 0.7205 | 0.7119 |

w_sEMG 차이: Wilcoxon **W=157, p=0.0087**.

**해석**: attention 게이트는 데이터셋 제작자가 EMG 템플릿 상관으로 "실제 움직임"이라 표시한 trial에서
sEMG 스트림에 유의하게 더 의존합니다. 이는 게이트가 적어도 부분적으로는 **움직임 아티팩트에 반응**한다는
직접 증거입니다. 다만 오염 trial의 정확도가 clean보다 높지 **않다**는 점(0.7119 < 0.7205)은,
움직임이 단순히 "쉬운 trial"을 만든 것은 아님을 시사합니다.

> 평가 측 오염 기여는 0.85%p로 작습니다. 따라서 v4 fusion 성능의 대부분은 평가 오염으로 설명되지 않습니다.
> **학습된 표현 자체가 오염됐는지**는 주 분석(재학습)으로만 답할 수 있습니다.
